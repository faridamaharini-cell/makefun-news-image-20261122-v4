One image that sums up the world's news of Sunday 22 November 2026: a cream
newspaper front page with 37 verified stories across 7 regions. Three lead
stories (186 drones over Ukraine; the COP31 deal lands with no mention of
fossil fuels; Iran's radar claim meets Bahrain's denial), twelve illustrated
grid stories, a 22-story also-list, a numbers strip, a UTC timeline, a world
map with pins, and a DATE CHECK box that names the earlier days' news left
out. Every scene carries a red hook tag and a certainty badge (REPORTED /
CLAIM / CONFIRMED); region counts are computed from the story data, so the
bar always sums to the headline count.

## Run

```sh
node main.ts
```

It copies `entry.png` to `/output/entry.png` (1024x1024 PNG). Node 22,
standard library only, no network. Running it twice produces byte-identical
output.

Scenes are drawn illustrations, not photographs. Sources: Reuters, BBC, AP,
AFP, Al Jazeera, The Guardian, Ukrainian Air Force, SCMP, ESPNcricinfo,
Detiknews, Vatican News.
